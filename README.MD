# Sanoat Sanitariyasi va Mehnat Muhofazasi 🚧

Bu loyiha "Hayot faoliyati xavfsizligi" va "Sanoat sanitariyasi" fanlari uchun mo'ljallangan interaktiv o'quv veb-sayti. O'qituvchilar dars jarayonida talabalar bilimini mustahkamlash va sinash uchun qulay vosita sifatida foydalanishlari mumkin. 

## 🌟 Imkoniyatlari

*   **Zamonaviy dizayn:** Sanoat (industrial) uslubiga xos xavfsizlik sariq va qora ranglar uyg'unligi.
*   **Nazariy qism:** Shamollatish, yoritish, shovqin va shaxsiy himoya vositalari (SHV) haqida qisqacha vizual ma'lumotlar.
*   **Interaktiv test (Viktorina):** Bilimni sinash uchun maxsus 40 ta savoldan iborat o'yin.
*   **Natijalarni hisoblash:** Test yakunida to'g'ri va noto'g'ri javoblarni avtomatik hisoblash va ko'rsatish tizimi.
*   **Moslashuvchan (Responsive):** Kompyuter, planshet va smartfonlarda ekran o'lchamiga moslashib chiroyli ko'rinadi.

## 🛠 Texnologiyalar

Loyiha to'liq bitta fayl (`index.html`) ichida yozilgan va quyidagi texnologiyalardan foydalanilgan:
*   **HTML5** - Veb-sayt strukturasi
*   **Tailwind CSS** (CDN orqali) - Zamonaviy va tezkor dizayn yaratish uchun
*   **JavaScript (Vanilla JS)** - Test logikasi va interaktivlik uchun

## 🚀 Qanday ishga tushiriladi?

Hech qanday qo'shimcha dastur yoki server o'rnatish talab qilinmaydi.
1. Loyihani yuklab oling yoki klonlang: `git clone https://github.com/NurmuhammadMerajov/sanitariya-sayti.git`
2. Papka ichidagi `index.html` faylini ustiga ikki marta bosib istalgan brauzerda (Chrome, Edge, Safari va h.k.) oching.
